# 🚀 About The Project

**Checkmate Reels** is not another traditional chess website.

It’s a modern AI-native chess platform that combines:

The goal of the project is to transform chess from a static board game into an emotional, entertaining, and highly engaging experience for the next generation of players.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

### Supabase (optional)

1. Create a Supabase project
2. Copy `.env.example` to `.env`
3. Add your URL and anon key
4. Create a `games` table:

```sql
create table games (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users not null,
  pgn text not null,
  result text not null,
  highlights jsonb,
  coach_id text,
  created_at timestamptz default now()
);
```

Without Supabase, everything works in **fully offline local mode**.

## Local database (for moderators)

No setup required. Stats are stored in the browser via **IndexedDB**:

| Table | Stores |
|-------|--------|
| `users` | Profile (username, avatar, coach) |
| `stats` | Wins, losses, draws, games played |
| `games` | Match history + reels data |

### Profile → Local database

- **Export JSON** — download portable backup (`checkpulse-username-date.json`)
- **Import JSON** — restore stats on any machine
- **Load demo** — pre-filled 3W / 2L / 1D sample (`public/demo-stats.json`)
- **Clear local** — reset IndexedDB

Share the exported JSON file with moderators — they click **Import JSON** after `npm run dev`.
